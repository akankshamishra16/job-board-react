# 💼 DevJobs - React Job Board Web Application

🌐 **Live Demo:** (https://capable-taffy-726178.netlify.app)

A clean, responsive, and interactive Job Board application built from scratch using React, JavaScript, and custom CSS. This application allows job seekers to browse, search, and filter job listings, view detailed role specifications via modals, post new listings live, and toggle between Light and Dark themes.

---

## ✨ Key Features

- **25+ Realistic Job Listings:** Includes detailed roles across Engineering, Design, Marketing, and Product management.
- **Instant Search & Category Filtering:** Search by job title or company name in real time, or filter listings by specific job categories.
- **Job Details Modal:** Click on any job card to view full role descriptions, required qualifications, location, salary, and submission options.
- **Interactive "Post a Job" Form:** Add new job postings directly to the main feed dynamically.
- **Dark Mode Support:** Seamless theme switching with persistent CSS variable styling for dark and light modes.
- **Fully Responsive UI:** Optimized for seamless viewing across mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **Frontend Library:** React (Vite)
- **Language:** JavaScript (ES6+)
- **Styling:** Custom Vanilla CSS (Flexbox & Grid)
- **Deployment & Version Control:** Git & GitHub
